# Security

Report vulnerabilities privately using GitHub private vulnerability reporting once enabled for this repository. Until that is enabled, contact the repository maintainer privately; do not post credentials or exploit details in public issues.

Instance operators manage their own Cloudflare permissions, email configuration, endpoint secrets, backups, and updates. Keep the first administrator's email secure. Disable a compromised user's account to revoke browser/API credentials and invalidate OAuth grants, then reconnect only after account recovery.

See the validation guide for deployment and security checks. Automated checks are not a third-party penetration test.
