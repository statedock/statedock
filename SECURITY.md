# Security

Report security vulnerabilities privately to [support@statedock.dev](mailto:support@statedock.dev). Do not post credentials, personal data, or exploit details in public issues. Include the affected version, reproduction steps, and likely impact; never include live secrets.

GitHub private vulnerability reporting is available only for public repositories. This repository currently remains private, so email is the reporting channel. Before public release, maintainers must enable private vulnerability reporting and update this policy with the GitHub reporting link.

Instance operators manage their own Cloudflare permissions, email configuration, endpoint secrets, backups, and updates. Keep the first administrator's email secure. Disable a compromised user's account to revoke browser/API credentials and invalidate OAuth grants, then reconnect only after account recovery.

See the validation guide for deployment and security checks. Automated checks are not a third-party penetration test.
